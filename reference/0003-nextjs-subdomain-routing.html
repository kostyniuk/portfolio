Subdomain Routing

A subdomain route has three jobs: DNS makes the hostname reach Vercel, Vercel assigns that hostname to a project and provisions HTTPS, then Next.js decides what page that hostname should render.

The Layers

DNS

Make www.lovable.a13x.space resolve to Vercel by adding the CNAME record Vercel recommends.

Vercel project domain

Add www.lovable.a13x.space to Project Settings -> Domains so Vercel can serve this project and issue HTTPS.

Next.js routing

Once the request reaches the app, use the request Host header to map / on that host to an internal page.

DNS Terms

Term Use it for
A record Point a hostname directly to an IPv4 address. Vercel uses this for apex domains such as a13x.space.
CNAME record Point a subdomain to another hostname. Vercel uses this for subdomains such as www.lovable.a13x.space.
Name The prefix inside the current DNS zone. Inside a13x.space, use www.lovable, not the full hostname.
Value The target. Copy Vercel's recommended CNAME exactly, including the final dot when shown.
TTL Cache lifetime for DNS resolvers. 60 is a short, normal value during setup.

Pattern Used Here

async rewrites() {
  return {
    beforeFiles: [
      {
        source: "/",
        has: [
          {
            type: "host",
            value: "www\\.lovable\\.a13x\\.space(?::\\d+)?",
          },
        ],
        destination: "/lovable",
      },
    ],
  };
}

Why `beforeFiles`?

The normal portfolio homepage already exists at /. A beforeFiles rewrite can override that filesystem page for only the matching host. Because the source is exactly /, static assets such as /lovable/pulse.webp and /_next/* still pass through normally.

Local Test

npm run dev
curl -H "Host: www.lovable.a13x.space:3000" http://127.0.0.1:3000/

If you want to use a browser, add 127.0.0.1 www.lovable.a13x.space to /etc/hosts, then open http://www.lovable.a13x.space:3000/.

Deployment Checklist

  1. Add www.lovable.a13x.space to the Vercel project domains.
  2. Open the domain row and read Vercel's recommended DNS record.
  3. Add the CNAME record in the a13x.space DNS zone.
  4. Deploy the code containing the host rewrite.
  5. Refresh the Vercel domain row until it says the configuration is valid.
  6. Visit https://www.lovable.a13x.space/ after DNS and SSL finish provisioning.
