CSS Animation Field Guide

A compact map for choosing the right animation primitive.

Transition

Use when an element changes between two states, like hover, open, selected, or visible.

.button {
  transition: transform 180ms ease;
}
.button:hover { transform: translateY(-2px); }

Time-Based Keyframes

Use when motion has multiple beats, repeats, delays, or a named sequence.

.logo {
  animation: pulse 900ms ease-in-out both;
}
@keyframes pulse {
  50% { scale: 1.08; }
}

@starting-style

Use when an element needs a synthetic first style as it enters the page or changes from not-rendered to rendered.

.toast {
  transition: opacity 200ms, translate 200ms;
  @starting-style {
    opacity: 0;
    translate: 0 0.5rem;
  }
}

Scroll-Driven Progress

Use when the animation frame should be controlled by scroll position.

.progress {
  animation: fill linear both;
  animation-timeline: scroll(root block);
}

Scroll-Triggered Range

Use when an enter or exit animation should happen inside a specific part of a view timeline.

.card {
  animation: reveal linear both;
  animation-timeline: view();
  animation-range: cover 0% cover 20%;
}

View Transition

Use when the browser should animate between old and new snapshots of a page or app state.

::view-transition-old(root),
::view-transition-new(root) {
  animation-duration: 420ms;
}
