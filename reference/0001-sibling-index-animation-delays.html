sibling-index() Animation Delays

A quick pattern for making sibling elements animate one after another without writing a selector for every child.

Mental Model

  • sibling-index() returns the current element's position among its siblings.
  • The first child is 1, not 0.
  • Use it inside calc() when CSS expects a number-like value.
  • For a delay that starts at 0ms, subtract 1.

Core Formula

.item {
  --step: 90ms;
  animation-delay:
    calc((sibling-index() - 1) * var(--step));
}

Reusable Pattern

.list > * {
  --step: 90ms;
  animation: rise 420ms ease both;
  animation-delay: calc((sibling-index() - 1) * var(--step));
}

@keyframes rise {
  from {
    opacity: 0;
    transform: translateY(10px);
  }
  to {
    opacity: 1;
    transform: translateY(0);
  }
}

Progressive Enhancement

Use sibling-index() directly when staggered motion is an enhancement. The content remains readable even if the motion feature is unavailable.

.list > * {
  --step: 90ms;
  animation-delay: calc((sibling-index() - 1) * var(--step));
}
