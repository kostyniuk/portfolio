The Shimmer Underline

Skill: draw a grey underline that grows out from the left, then send a single shot of rainbow colour slipping across it — like a progress sweep — then back to grey. It's the second half of the x.ai hero, and the demo below shows the two combined.

The Problem This Solves

You want a moment of colour that travels — a highlight that sweeps along a bar and is gone — not a static gradient that just sits there glowing. The naive instinct is to animate the gradient's colours, or to slide a separate coloured element along behind a mask. Both are awkward: colour interpolation across many stops looks muddy mid-transition, and a second moving element means extra DOM and z-index juggling.

The clean trick is counterintuitive: the gradient never changes, and nothing moves the colour — you move the window you're viewing the gradient through. Bake the colour into a gradient that is much wider than the bar, show only a slice of it, and animate which slice is visible. The colour appears to fly across, but you only ever animated one cheap property: background-position.

The Idea: A Wide Gradient, A Narrow Window

Think of the bar as a letterbox slot and the gradient as a long strip of film behind it. The strip is grey for most of its length with one rainbow patch in the middle. background-size: 400% makes the strip four times wider than the slot, so at any instant the slot shows only a quarter of it — usually just grey.

Now slide the strip with background-position. As the rainbow patch drifts past the slot, you see a shot of colour cross the bar, then grey returns. Separately, the bar itself grows in with transform: scaleX(0) → 1 and transform-origin: left, so it draws on from the left edge before the colour runs through it.

The Recipe

.underline {
  height: 3px; border-radius: 999px;
  transform-origin: left;
  background-image: linear-gradient(90deg,
    grey 0%, grey 35%,
    #6366f1 40%, #a855f7 45%, #ec4899 50%,
    #f97316 55%, #eab308 60%,
    grey 65%, grey 100%);
  background-size: 400% 100%;   /* strip 4x the slot */
}
@keyframes u-grow {            /* draw the bar on */
  from { opacity:0; transform: scaleX(0); }
  to   { opacity:1; transform: scaleX(1); }
}
@keyframes u-shimmer {         /* slide the strip */
  from { background-position: 100% 50%; }
  to   { background-position:   0% 50%; }
}
.underline {
  animation:
    u-grow   360ms ease-out  both,
    u-shimmer 3s   linear  1 both;
}

Note x.ai folds both motions into a single hero-shimmer keyframe; splitting them into u-grow + u-shimmer is the same result and easier to read and retune.

The Boundaries

Animate background-position, not the colours. Tweening between many colour stops produces muddy in-between frames; moving the viewport over a fixed gradient keeps every colour crisp. This is the same "move the window, not the content" idea behind classic skeleton-loader shimmers.

Wider strip = tighter, faster-looking shot. A bigger background-size means the rainbow band occupies a smaller fraction of the visible slot, so the colour reads as a thin streak; a smaller size fattens it toward a full-bar wash. It's your main expressiveness dial.

It's decoration — mark it as such. The bar carries no information, so it's aria-hidden and guarded by prefers-reduced-motion (the colour just settles instead of sweeping). If you instead want a bar that fills in proportion to real progress, that's a different tool — a width/scale bound to a value, not a cosmetic sweep.

One run, not a loop. x.ai plays the shimmer once (animation-iteration-count: 1) as part of the entrance. A looping shimmer is for ongoing states like loading — see Lesson 6 on iteration and direction before you make anything repeat.

On Your Portfolio

Use this to make one word of a heading — or a section title — feel "lit": wrap the word in a relative span, drop an absolutely-positioned .underline inside it, and it draws on and flashes colour as the heading reveals. It pairs naturally with the flip-up for a hero, but stands alone under any link or label you want to draw the eye to. Still zero animation libraries: one extra span and two keyframes.

One piece remains: on x.ai the underlined word doesn't just sit there — it rotates to a new word every couple of seconds while this bar stays put beneath it. Lesson 14 builds that rotating word and runs all three techniques as the complete hero.
