Stagger With sibling-index()

Tiny win: make sibling elements animate one after another by deriving each delay from its DOM position.

Progressive Enhancement

This lesson uses sibling-index() directly, so the CSS can derive each item’s place without repeated index rules.

The One Idea

sibling-index() returns an integer for the current element's position among its siblings. The first child returns 1, so subtract 1 when you want the first item to start immediately.

delay = (sibling-index() - 1) x step 
.item {
  --step: 120ms;
  animation-delay:
    calc((sibling-index() - 1) * var(--step));
}

Progressive Enhancement Rule

Keep the markup plain and let modern CSS derive the index. The content stands on its own; the staggered motion is the enhancement.

.item {
  --step: 120ms;
  animation-delay: calc((sibling-index() - 1) * var(--step));
}
