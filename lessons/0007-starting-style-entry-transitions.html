Give New Elements A Before State

Skill: use @starting-style when an element needs entry transition styles the moment it appears.

The Problem This Solves

A transition needs two things: a previous style and a new style. But a newly rendered element has no previous style — when a toast mounts, or an element flips from display: none to visible, there is nothing to transition from. So it pops in fully formed, and your carefully written transition line does nothing.

For years the workarounds were all JavaScript hacks: insert the element with a "hidden" class, force a reflow (or wait one requestAnimationFrame), then remove the class so the browser perceives a change. Fragile, easy to get wrong, and pure ceremony — the developer's actual desire was just: "when this thing first appears, pretend it started over here."

@starting-style says exactly that, in CSS.

The Idea: A Synthetic "Before"

The @starting-style block supplies the missing previous style. On the element's first styled frame, the browser uses these values as the transition's starting point — so the normal style becomes the destination, and the entry animates like any other state change. It only applies at first render; after that, the element transitions between its real states as usual.

Demo

Saved. This toast transitions from its starting style.
.toast {
  transition: opacity 240ms ease, translate 240ms ease;

  @starting-style {
    opacity: 0;
    translate: 0 .75rem;
  }
}

Note what the JavaScript in this demo does: it toggles hidden and nothing else. All the entry motion lives in CSS — that's the whole point.

The Boundaries

@starting-style handles entry. The exit (transitioning to display: none) is a separate problem with a separate tool — transition-behavior: allow-discrete — because display isn't an interpolatable property. And if the entry needs multiple beats rather than a single glide, use a keyframes animation instead: animations always play on mount, so they never had this problem in the first place. @starting-style is specifically for when you want the transition model (two states, reactive, reversible) to also cover first render.

On Your Portfolio

This is the tool for toasts, dropdown menus, dialogs, and anything rendered conditionally by React. Conditional rendering ({isOpen && <Toast />}) mounts a brand-new element every time — exactly the "no previous style" case — so @starting-style lets those components animate in without effects, refs, or animation libraries.
