# Mission: Modern CSS Animation Patterns

## Why
Learn modern CSS features that make portfolio interactions easier to author, especially animations that react to document structure without repetitive per-item classes.

## Success looks like
- Create staggered animations where sibling elements animate in sequence.
- Understand when `sibling-index()` is enough and when a fallback is needed.
- Apply the pattern cleanly in small UI sections without adding JavaScript for simple timing.

## Constraints
- Keep lessons quick and practical.
- Prefer examples that can be reused in this portfolio workspace.
- Avoid broad browser or build-system detours unless they affect the pattern.

## Out of scope
- Full animation theory.
- Complex motion libraries.
- Large refactors of the portfolio app.
