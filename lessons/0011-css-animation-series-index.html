CSS Animation Series

Work through these in order. Lessons 1 and 2 are the sibling-index warmup already in this workspace; lessons 3-10 broaden into the animation toolkit; lessons 12-15 are a real-world case study — rebuilding x.ai's hero effect (flip-up, shimmer underline, rotating word) from the toolkit, ending in a dynamic React component shipped to this portfolio. Each lesson explains the problem the feature solves, the idea behind it, and where it fits on this portfolio.

  1. Sibling index animation delays - derive stagger timing from DOM order instead of per-item classes.
  2. Apply sibling-index to contribution vitals - use real portfolio markup.
  3. Animation primitives map - four primitives, distinguished by what drives the progress: state change, clock, scrollbar, or snapshot diff.
  4. Transitions for state changes - fix the "instant snap" of style changes by describing two states and letting the browser interpolate.
  5. Keyframes for time-based sequences - when two states aren't enough: loops, middle beats, and self-starting motion as a named, reusable timeline.
  6. Easing, fill mode, and direction - fix robotic motion, the flash-before-delay bug, and the loop snap.
  7. @starting-style entry transitions - new elements have no "before" state to transition from; this supplies a synthetic one, replacing JS reflow hacks.
  8. Scroll-driven progress - replace laggy JS scroll listeners by making scroll position the animation's clock.
  9. Scroll-triggered animation ranges - crop a view timeline so reveals finish while the element is being read, not as it leaves.
  10. View transitions between states - animate structural changes (reorders, navigation) by morphing browser snapshots — FLIP without the JavaScript.
  11. The x.ai 3D flip-up reveal - reveal a headline word-by-word with depth using perspective + rotateX, rebuilt from x.ai's hero.
  12. The gradient shimmer underline - grow a grey bar and slip a shot of colour across it by moving background-position over an oversized gradient.
  13. The rotating word ticker - swap the last word on a ~2s beat with a CSS reel; combines all three into the complete x.ai hero.
  14. Capstone: the dynamic hero - the JS upgrade: underline resizes per word and the shimmer replays on every swap. Shipped as a real portfolio component.
