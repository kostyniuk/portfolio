The Rotating Word

Skill: swap the last word of a headline for another every couple of seconds — "everything you build … create … discover" — as a looping vertical ticker, while a fixed underline stays put beneath. This is the final piece of the x.ai hero; the demo below runs all three techniques together.

The Problem This Solves

One headline, many claims. xAI doesn't want to say only "everything you build" — they want the sentence to keep re-completing itself with build, create, discover, imagine, so a single line advertises a whole range. Hard-coding one word undersells it; shipping four separate headlines is clumsy; and reaching for an animation library just to rotate a word adds a dependency for what is, at heart, copy.

The desire is simple: show a sequence of words in the same spot, one at a time, on a steady beat, forever. On x.ai this is done in JavaScript (the outgoing and incoming word are briefly stacked in the markup — the tell-tale duplicated <span>build</span> the snapshot captured). But when the word list is fixed and known, CSS alone can do it — and that fits this workspace's no-library goal.

The Idea: A Reel Behind A Slot

Stack the words in a vertical column — a film reel. Put a one-line-tall window over it with overflow:hidden so only one word shows. Then scroll the reel up by exactly one line-height to bring the next word into the slot, pause, scroll again. The motion is a single translateY.

The trick that makes it loop seamlessly: repeat the first word at the bottom of the reel. The animation ends parked on that duplicate — pixel-identical to where it started — so when the loop resets there's no visible jump. And the "2-second timer" isn't a timer at all: it's a hold in the keyframes, the same value repeated across two adjacent percentages so the reel sits still between slides.

The Recipe

.rotator {                 /* the slot */
  display: inline-block;
  height: 1.2em;
  overflow: hidden;
}
.reel > span {             /* each word, one line tall */
  display: block;
  height: 1.2em;
}
@keyframes reel {
  0%,  20% { transform: translateY(0); }        /* hold word 1 */
  25%, 45% { transform: translateY(-1.2em); }   /* hold word 2 */
  50%, 70% { transform: translateY(-2.4em); }   /* hold word 3 */
  75%, 95% { transform: translateY(-3.6em); }   /* hold word 4 */
  100%     { transform: translateY(-4.8em); }   /* dup of word 1 */
}
.reel { animation: reel 10s cubic-bezier(.7,0,.3,1) infinite; }

Idea a multi-step @keyframes is just a timeline through N states. A pair of equal percentages = a dwell; the gap between pairs = the slide. (See Lesson 5.)

The Boundaries

The slot sizes to the widest word. A vertical stack makes the container as wide as its longest entry, so the underline holds one steady width while words swap — clean, but it means short words sit in a wider box. If you need the box (and underline) to resize per word, that's a width animation the browser can't infer from a stack — which is exactly why x.ai uses JS layout animation there.

CSS rotator vs. JS rotator. The CSS reel is perfect for a fixed, known list with uniform styling and no interaction. Reach for JS (an index + interval, or a library's presence animation) when the words come from data, each needs its own enter/exit, or it must pause on hover/focus. x.ai chose JS because their list is content; you can choose CSS because yours is decoration.

Looping motion needs a reason — and an off switch. Unlike the flip-up and the underline (which play once), this runs forever, so it's the most attention-grabbing piece. Keep the beat calm (~2s), and honour prefers-reduced-motion by freezing on a single word — this lesson does exactly that. Revisit Lesson 6 for how iteration and easing shape a loop.

On Your Portfolio

Use a rotating word in your hero tagline to span your range without a wall of text — "I build / design / ship …". Wrap the swappable word in a .rotator slot over a .reel of spans, remember the duplicate-first-word trick for a seamless loop, and you have a self-contained, dependency-free ticker. Combined with the flip-up and shimmer underline from the previous two lessons, that's the entire x.ai hero — rebuilt from this series' primitives, with zero animation libraries in your bundle.
