Keyframes Give Motion Beats

Skill: use percentages to define a sequence over time.

The Problem This Solves

Transitions interpolate between exactly two states, and only when something changes. That model breaks down the moment you want any of these:

A middle beat. "Overshoot, then settle" is three states, not two. A loop. A pulsing badge never stops — there's no end state to transition to. Autonomous motion. An entry animation on page load has no hover or class flip to react to; it just needs to play. Reuse. A transition lives on one selector; you can't name it and apply it elsewhere.

Keyframes exist because designers wanted choreography — multi-step, repeatable, self-starting motion — declared in CSS instead of a JavaScript timer loop.

The Idea: Separate The Dance From The Dancer

A @keyframes block is a named, reusable timeline. Percentages are positions in that timeline — not times. 35% means "at 35% of however long this plays," so the same choreography works at 300ms or 3s without editing a single keyframe.

The animation property is the casting call: it picks which element performs the timeline, at what duration, with what easing, and how many times. One @keyframes block can drive twenty different elements at twenty different speeds. This separation — motion defined once, applied anywhere — is what makes patterns like the sibling-index stagger possible: every item runs the same keyframes, only the delay differs.

NEW
.badge {
  animation: badge-pop 1.5s ease-in-out infinite both;
}

@keyframes badge-pop {
  0%        { opacity: .35; scale: .84;  rotate: -3deg; }
  35%       { opacity: 1;   scale: 1.08; rotate: 2deg;  }
  60%, 100% { opacity: 1;   scale: 1;    rotate: 0deg;  }
}

Reading The Choreography

Three beats: start dim and small (0%), overshoot past full size (35%) — overshoot is what makes motion feel alive rather than mechanical — then settle (60%). Listing 60%, 100% together pins the same style to both points, which creates a hold: the badge rests for the final 40% of each loop instead of immediately popping again. Holds are how you give looping motion a rhythm.

On Your Portfolio

Keyframes are your tool for anything that plays on its own: entry reveals, attention pulses on a "NEW" badge, looping accents. They also become the raw material for scroll-driven animations — same @keyframes syntax, different clock.
